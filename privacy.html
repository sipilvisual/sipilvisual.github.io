Kebijakan Privasi Sipil Visual Tools

Berlaku sejak 26 November 2026.

Data yang diakses

Dengan izin pemilik akun lewat Google OAuth, alat ini mengakses data kanal YouTube milik pemilik sendiri: daftar video, judul, deskripsi, tag, komentar, dan statistik/analitik kanal. Alat ini juga dapat mengunggah video dan membalas komentar atas nama kanal tersebut.

Cara data dipakai dan disimpan

  • Data hanya dipakai untuk mengelola kanal Sipil Visual oleh pemiliknya sendiri.
  • Token akses disimpan di komputer pemilik, tidak di server mana pun.
  • Data tidak dijual, tidak dibagikan, dan tidak dipindahkan ke pihak ketiga.

Mencabut akses

Akses dapat dicabut kapan saja di myaccount.google.com/permissions.

Penggunaan data dari Google API mengikuti Google API Services User Data Policy, termasuk ketentuan Limited Use, dan YouTube Terms of Service.

English: This tool only accesses the owner's own YouTube channel data with the owner's consent. Tokens are stored locally on the owner's computer. Data is never sold or shared with third parties. Access can be revoked at myaccount.google.com/permissions.
